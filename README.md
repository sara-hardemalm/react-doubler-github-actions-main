# Dubbleraren

En mycket enkel React-app för en nybörjarövning med Vitest och GitHub Actions.

## Starta appen

```bash
npm install
npm run dev
```

## Kör testerna en gång

```bash
npm run test:run
```

Projektet innehåller inga GitHub Actions-filer. De skapas steg för steg i den tillhörande Word-guiden.
